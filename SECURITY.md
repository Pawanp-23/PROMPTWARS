# Security

| Risk                         | Mitigation                                                                                                                                                                             | Where                                               |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| API key exposure             | Gemini is called only from the server; the key is read from the environment and never sent to the browser. `.env` is git-ignored; `.env.example` documents it.                         | `server/index.ts`, `server/engine/gemini.ts`        |
| Malformed or oversized input | zod schema with per-field length limits; 20 KB JSON body limit (413).                                                                                                                  | `shared/schema.ts`, `server/app.ts`                 |
| Abuse / cost exhaustion      | Per-IP rate limit (20 requests/min) on `/api/analyze`; TTL cache for repeated requests.                                                                                                | `server/app.ts`, `server/engine/cache.ts`           |
| Prompt injection             | User text is sent as JSON inside `<user_decision>` tags; the system prompt marks it as data, not instructions; output is schema-validated and passed through the recommendation guard. | `server/engine/prompt.ts`, `server/engine/guard.ts` |
| Hallucinated content         | Quotes are shown only if they appear verbatim in the user's input.                                                                                                                     | `server/engine/quotes.ts`                           |
| XSS                          | React escapes all rendered text; no `dangerouslySetInnerHTML`; strict Content-Security-Policy (`default-src 'self'`, `frame-ancestors 'none'`).                                        | `server/app.ts`                                     |
| Information leakage          | `x-powered-by` disabled; errors return generic messages; details are logged server-side only.                                                                                          | `server/app.ts`, `server/routes/analyze.ts`         |
| Container hardening          | Multi-stage build, production dependencies only, runs as non-root `node` user.                                                                                                         | `Dockerfile`                                        |
| Privacy                      | No accounts, no database, nothing persisted server-side.                                                                                                                               | —                                                   |

Report issues by opening a GitHub issue.
